# THE REDMONT JOURNAL: approved social media slides

This public repository holds **only slides already approved by the founder**, so that Metricool can read them from a public address when a post is scheduled (founder decisions 48; option A, 4 November 2026).

**Rules:**
- Nothing unapproved is ever pushed here. Slides are added only right before an approved post is scheduled.
- One folder per approved package version, for example `the-bible-foundation/v1/01-cover.png`.
- Files are never changed after they are pushed. A new version gets a new folder.
- No drafts, no source files, no captions with unpublished material, no personal data, no tokens.

The working files, approvals and records are in the Journal's private repository.
